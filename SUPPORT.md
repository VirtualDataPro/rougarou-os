# Getting help

Start with the [installation guide](docs/first-test.md),
[Proxmox guide](docs/proxmox.md), [cloud image guide](docs/cloud-image.md)
and [tested configurations](docs/validation.md).

Ask setup and usage questions in
[GitHub Discussions](https://github.com/VirtualDataPro/rougarou-os/discussions).
Include your Rougarou version, ISO or cloud-image installation method, VM
configuration, steps tried and redacted error output. Run `rougarou doctor`
inside your Rougarou VM when relevant and share only redacted output.

File reproducible defects through the
[bug report form](https://github.com/VirtualDataPro/rougarou-os/issues/new?template=bug_report.yml).
Use Discussions for product suggestions that need exploration, then open a
feature proposal when the problem and expected outcome are clear.

Support is provided by the community as time permits. Rougarou is experimental;
evaluate releases in a separate VM and consult release-specific validation before
installing. Report suspected vulnerabilities through [SECURITY.md](SECURITY.md).
