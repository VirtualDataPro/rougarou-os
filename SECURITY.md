# Reporting security concerns

Rougarou OS is in public alpha. Security fixes target the current alpha and future
releases; older alpha builds do not have a guaranteed maintenance window. Debian
packages also depend on the upstream Debian security update process.

Avoid posting exploit details, credentials or private infrastructure information
in public issues or discussions. If GitHub offers **Report a vulnerability** on
this repository's Security tab, use that private reporting form. Otherwise use a
private contact method listed on the repository owner's GitHub profile if available.
If neither is available, open an issue asking for a private reporting channel and
omit vulnerability details until one is provided.

Include the affected release, component, impact and reproduction steps in the
private report. Use a disposable VM and synthetic data when demonstrating a
problem. Do not include real secrets. Reports are reviewed as maintainer time
permits; no response deadline or bounty is promised.
